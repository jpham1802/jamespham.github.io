# Icons

This directory should contain icon files in PNG format:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

You can create simple icons using any image editor, or use the provided icon.svg as a template.

The extension will work without icons, but they won't display properly in the browser.

To create icons from the SVG:
1. Open icon.svg in an image editor (like GIMP, Photoshop, or online tools)
2. Export it as PNG at the required sizes
3. Save them with the correct filenames

Alternatively, use an online SVG to PNG converter.
